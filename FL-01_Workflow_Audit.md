## 2. Three Target Tasks to carry into FL-02 → FL-04

These are the tasks I will reuse and improve across the next three phases.

### Target Task 1 — Learn a new frontend skill (just me → improved with AI)
- **What:** Pick one frontend concept per week (e.g., flexbox, grid, closures, promises) and genuinely learn it.
- **Done well:**
  - I can explain the concept in my own words without looking at notes.
  - I build a small working example from a blank editor (no copy-paste).
  - I pass a self-made 5-question recall quiz with 4/5 correct.
  - I can teach it back to Claude conversationally and it confirms my understanding.

### Target Task 2 — Build a practice project (collaborate with AI)
- **What:** Finish the current employee management system and then build one new full frontend project.
- **Done well:**
  - The project runs without errors and is responsive on mobile and desktop.
  - Core features work (add/edit/delete, data persistence via JSON/localStorage).
  - I wrote the logic myself; AI only helped debug and suggest structure.
  - Code is organized into clear folders and follows consistent naming.

### Target Task 3 — Revise language commands (delegate to AI with review)
- **What:** Use AI to generate weekly revision quizzes and syntax summaries for HTML/CSS/JS.
- **Done well:**
  - I complete the AI-generated quiz each week and score 80%+.
  - I correct at least one misconception the quiz reveals.
  - Summaries are saved into my own notes file, edited by me to match my understanding.
  - I can write the commands from memory in a blank file.
