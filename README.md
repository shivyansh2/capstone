# Capstone

> A starter repository for the AI-assisted development capstone track.

## Overview

This repository is the foundation for a capstone project built with AI-assisted
development tooling (Claude Code / Blackbox AI). It is intentionally minimal at
the moment — the project scope will be defined in a later phase.

## Stack

| Layer    | Choice        |
| -------- | ------------- |
| Runtime  | Node.js (LTS) |
| Language | JavaScript    |
| Package  | npm           |

## Status

**Phase: Setup** — toolchain configured, repository scaffolded. Project scope
to be defined in the next phase.

## Getting Started

Prerequisites: [Node.js LTS](https://nodejs.org/) and npm.

```bash
# 1. Install dependencies
npm install

# 2. Run the application
npm start
```

Expected output:

```
Capstone v0.1.0 — setup phase complete.
```
